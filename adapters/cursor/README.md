# Tevra with Cursor

Install using `tevra-design init --yes --agents cursor --root <project>`. Project skills live in `.cursor/skills/<name>/SKILL.md` with their focused references. Cursor also documents compatibility paths, but Tevra uses its native project directory to avoid assuming identical agent behavior. Select a skill through `/` in Agent chat where supported.

Source: https://cursor.com/docs/skills . Remote/global sync and managed trust differ from local discovery. Installer tests establish file layout, not host activation.
