# Tevra with Windsurf

Install using `tevra-design init --yes --agents windsurf --root <project>`. Skills install to `.windsurf/skills/<name>/SKILL.md`, which Cascade reads in both older Windsurf releases and current Devin Desktop (whose primary workspace path is `.devin/skills/`). Cascade activates a skill from its description or an `@skill-name` mention. Keep project rules in `.windsurf/rules/`.

Source: https://docs.windsurf.com/windsurf/cascade/skills . The product is changing; verify the path against the installed version. Installer tests establish file layout, not host activation.
