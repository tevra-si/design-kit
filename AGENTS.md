# Tevra Design Kit repository instructions

For product UI and design-system work in this repository, use the installed project skills under `.agents/skills/`:

- Start with `design-research` when the brief, user needs, current UI, or system constraints need investigation.
- Use `design-direction` before substantial new visual work or redesign.
- Use `design-system` for scoped token/theme work and `ui-builder` to implement the approved direction.
- Use `ui-redesign` for existing UI, `responsive-design` for layout adaptation, and `interaction-motion` for purposeful feedback.
- Use `accessibility-qa` for automated and manual accessibility evidence.
- Use `visual-review` after a rendered UI change when screenshots/browser output are available.

Read the relevant `SKILL.md` before that phase. The matching source copies are in `skills/`; keep both locations synchronized when editing skill content. The schema, rubric, templates, and example workflow are shared references in this repository.

Always inspect and prioritize the active project design system. Do not create a parallel set of tokens or components. Follow project-specific instructions and approved design decisions ahead of Tevra examples.

Write all repository content (docs, README, skills, comments, commit messages) in English. Vietnamese keywords in the router and UX catalog are intentional search terms.
