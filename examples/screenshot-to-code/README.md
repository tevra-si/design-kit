# Screenshot-to-code workflow

Capture a real built example after browser prerequisites pass; that PNG can become a reference for a new implementation. Record its route, state, viewport, theme and context revision. Ask design-direction to extract visible layout/type/color estimates and explicitly mark unseen interactions, fonts and breakpoint behavior as assumptions. Use ui-builder with the chosen framework, responsive-design for multiple widths and visual-review for comparison.

Do not infer responsive behavior from one image or copy unlicensed imagery. This directory contains workflow guidance, not a fabricated reference screenshot. No browser screenshot was generated in the current sandbox; use the capture command on a permitted host before starting image-based comparison.
