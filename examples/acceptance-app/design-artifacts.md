# Authored example design artifacts

These are original fixture artifacts for a local studio analytics application. They have not been approved by a real customer or generated by an executed external agent.

## Research recommendation

Audience: a small studio owner comparing quarterly revenue and evaluating plan cost. Prioritize month selection, clear summary metrics, a compact accessible data table and transparent local price calculation. Confidence: inferred from the example brief. Source: Tevra original scenario, not user research or a current trend survey.

## Visual direction

Editorial typography for primary headings; system sans for controls and data. Warm neutral page with restrained dark green actions. Controls: variance5, motion2, density5. Maintain clear grouping rather than identical cards for every block. Pricing articles are an intentional comparison pattern. Reduced-motion removes the optional button transition.

## Tokens and responsive rules

Primitive colors: canvas #f7f6ef, ink #18382c, accent #174f39, soft-surface #e6ede5, error #9d1f1f. Type: fluid heading2.25–4rem; body1rem; compact label. Spacing: .5,1,1.5,2,3,4rem. Border radius: .25rem on controls. Single-column content below48rem; three comparison columns when adequate width is available. Navigation wraps; dialogs remain within viewport. Visible focus outlines and 44px primary controls.

## Preserved invariants

Presentation before/after shares the same model and DOM listeners. Plan prices, seat range1–100, 20% annual discount, form validation, dialog Escape/return focus and reporting month calculations remain unchanged. No payment, email service or API is fabricated.

## Evidence status

Model unit tests and source build are executable. Browser, screenshots, contrast/axe and performance evidence must come from real executions; example rationale does not substitute for those reports.
