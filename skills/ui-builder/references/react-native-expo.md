# React Native / Expo

Preserve native navigation and data ownership. Use accessibilityRole/Label/State, native focus conventions, safe-area APIs and platform reduced-motion settings. Check font scaling, touch targets and VoiceOver/TalkBack. Use device/simulator tooling such as existing native test suites; Playwright only validates web output, never native views. References: https://reactnative.dev/docs/accessibility and https://docs.expo.dev/guides/accessibility/
