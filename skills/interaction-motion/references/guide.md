# Focused implementation guide

Use motion to connect state changes, communicate feedback or preserve spatial context. Timing depends on distance, platform and purpose; no single duration is universally correct. Spring parameters need device testing and an interruptible state model. Stagger only when it clarifies reading order; never delay access to the primary action. Reduced motion can replace movement with immediate state/opacity change. Web: CSS/WAAPI or an existing Motion library. Native: platform APIs and device evidence.
